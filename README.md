# Machine Learning Bootcamp

A hands-on, 6-day machine learning bootcamp. You work on your own laptop, with no cloud services.

## Syllabus

### [Day 1: Supervised learning](01-supervised-learning/)

Build two local checks for Fresh and Good, a fictional Bangkok online grocery.

- Classification asks who will place no paid order next month.
- Regression asks how many baht they will spend next month.

Work inside `01-supervised-learning/`. Notebooks sit at that folder's root. Shared Python helpers live in `lib/`. The Streamlit form is `app.py`. Day 1 dependencies are in that folder's `pyproject.toml`.

### [Day 2: Unsupervised learning](02-unsupervised-learning/)

Find two leaky columns, group the same customers, flag odd rows, and suggest products. The form has a Segments tab and a Recommendations tab. Work in `02-unsupervised-learning/`. Do not edit Day 1.

### [Reinforcement learning](03-reinforcement-learning/)

Play a four-machine game in NumPy. If you finish early, there is a small grid. This is the 15:10–16:00 block on Day 2. Work in `03-reinforcement-learning/`.

### [Day 3: Deep learning](04-deep-learning/)

Train a small neural net on churn, then a small CNN on product images. Log one run in MLflow. The form has a churn tab and an image tab. Work in `04-deep-learning/`. Do not edit Day 1 or Day 2.
