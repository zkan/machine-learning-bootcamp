# Machine Learning Bootcamp

A hands-on, 6-day machine learning bootcamp. You work on your own laptop, with no cloud services.

## Syllabus

### [Day 1: Supervised learning](01-supervised-learning/)

Build two local checks for Fresh and Good, a fictional Bangkok online grocery.

- Classification asks who will place no paid order next month.
- Regression asks how many baht they will spend next month.
